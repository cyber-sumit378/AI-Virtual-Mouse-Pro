# AI Virtual Mouse Pro 🚀
Control your PC mouse entirely with hand gestures using AI. No hardware required. 
Built with OpenCV, MediaPipe, and PyAutoGUI.

## Features
- 👆 **Move:** Index finger only
- 🖱️ **Left Click:** Pinch Index and Thumb
- 🖱️ **Right Click:** Pinch Thumb, Index, and Middle fingers
- 📜 **Scroll:** Index and Middle fingers up

## How to Run
1. Install Python 3.11
2. Run `pip install -r requirements.txt`
3. Run `python virtual_mouse.py`
